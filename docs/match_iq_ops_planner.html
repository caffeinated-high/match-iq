Why this project
One shared game-state schema feeds three real capabilities instead of three disconnected demos: predicting outcomes, valuing every decision a player makes (not just goals), and training an agent that can actually act. Every module is built on open, reproducible tools — StatsBomb data, the socceraction/VAEP library, Google Research Football — so nothing here depends on data or infrastructure you don't have access to.
Midway demo target — week 6
Predict module shows a real win-probability curve on an actual StatsBomb match. Strategize module shows VAEP player rankings running end to end via socceraction. Train module shows a visible training-reward curve for a PPO agent on one Football Academy scenario — it doesn't need to be good yet, it needs to be honestly training. Partial-but-real beats faked end-to-end.
